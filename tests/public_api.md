# db-core public API

Generated by `make public-api` (`cargo public-api`, `-ss` to omit blanket
and auto-trait impls -- otherwise every public type's `Send`/`Sync`/`Into`/
`From` auto-derivations dominate the diff). Regenerate with `make
public-api` whenever a change adds, removes, or changes the signature of a
`pub` item; `make check-public-api-fresh` (part of `make ci`) fails the
build if this file is stale, so a public API change without a regenerated
snapshot is a build failure, not a silent widening. Rendered for
`x86_64-unknown-linux-gnu` (CI's target) regardless of host, so
`fcntl::fsync` (macOS-only, #652) is consistently absent.
